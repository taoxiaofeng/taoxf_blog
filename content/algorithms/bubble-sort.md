## 概述

冒泡排序（Bubble Sort）是最经典的入门级排序算法之一。它的名字来源于排序过程中较大的元素会像气泡一样逐渐"浮"到数组的顶端（末尾）。

冒泡排序的核心思想非常简单：反复遍历待排序的数组，每次比较相邻的两个元素，如果它们的顺序错误（逆序）就交换它们。每一轮遍历结束后，当前未排序部分的最大元素会被移动到正确的位置。

由于其实现简单、易于理解，冒泡排序常被用作算法教学的入门示例，但在实际生产环境中因效率较低而较少使用。

## 算法原理

冒泡排序的工作方式如下：

1. 从数组的第一个元素开始，依次比较相邻的两个元素
2. 如果前一个元素大于后一个元素，则交换它们的位置
3. 对数组中每一对相邻元素重复步骤 2，一轮遍历结束后，最大的元素会被移动到数组末尾
4. 针对所有元素重复以上步骤（除了已经排好序的末尾元素）
5. 当某一轮遍历没有发生任何交换时，说明数组已经有序，可以提前结束

### 优化策略

- **提前终止**：如果某一轮遍历中没有发生交换，说明数组已经有序，可以立即终止
- **记录最后交换位置**：记录每轮最后一次交换的位置，该位置之后的元素都已有序，下一轮只需遍历到该位置即可

## 执行步骤

以数组 `[64, 34, 25, 12, 22, 11, 90]` 为例，展示冒泡排序的执行过程：

**第一轮遍历：**
- 比较 64 和 34 → 64 > 34，交换 → [**34, 64**, 25, 12, 22, 11, 90]
- 比较 64 和 25 → 64 > 25，交换 → [34, **25, 64**, 12, 22, 11, 90]
- 比较 64 和 12 → 64 > 12，交换 → [34, 25, **12, 64**, 22, 11, 90]
- 比较 64 和 22 → 64 > 22，交换 → [34, 25, 12, **22, 64**, 11, 90]
- 比较 64 和 11 → 64 > 11，交换 → [34, 25, 12, 22, **11, 64**, 90]
- 比较 64 和 90 → 64 < 90，不交换 → [34, 25, 12, 22, 11, 64, **90**]

第一轮结束，90 已到正确位置。

**第二轮遍历：**
- 比较 34 和 25 → 交换 → [**25, 34**, 12, 22, 11, 64, 90]
- 比较 34 和 12 → 交换 → [25, **12, 34**, 22, 11, 64, 90]
- 比较 34 和 22 → 交换 → [25, 12, **22, 34**, 11, 64, 90]
- 比较 34 和 11 → 交换 → [25, 12, 22, **11, 34**, 64, 90]
- 比较 34 和 64 → 不交换 → [25, 12, 22, 11, 34, **64**, 90]

第二轮结束，64 已到正确位置。

**第三轮遍历：**
- [25, 12, 22, 11, 34, 64, 90] → 经过多次交换 → [12, 22, 11, 25, **34**, 64, 90]

**继续执行直到排序完成：**
- 最终结果：[11, 12, 22, 25, 34, 64, 90]

## 代码实现

```java
public class BubbleSort {

    /**
     * 冒泡排序（带优化：提前终止）
     */
    public static void bubbleSort(int[] arr) {
        int n = arr.length;
        for (int i = 0; i < n - 1; i++) {
            boolean swapped = false;
            for (int j = 0; j < n - 1 - i; j++) {
                if (arr[j] > arr[j + 1]) {
                    // 交换相邻元素
                    int temp = arr[j];
                    arr[j] = arr[j + 1];
                    arr[j + 1] = temp;
                    swapped = true;
                }
            }
            // 如果本轮没有交换，说明已排序完成
            if (!swapped) {
                break;
            }
        }
    }

    public static void main(String[] args) {
        int[] arr = {64, 34, 25, 12, 22, 11, 90};
        bubbleSort(arr);
        System.out.println(java.util.Arrays.toString(arr));
        // 输出: [11, 12, 22, 25, 34, 64, 90]
    }
}
```

```python
def bubble_sort(arr):
    """冒泡排序（带优化：提前终止）"""
    n = len(arr)
    for i in range(n - 1):
        swapped = False
        for j in range(n - 1 - i):
            if arr[j] > arr[j + 1]:
                # 交换相邻元素
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
                swapped = True
        # 如果本轮没有交换，说明已排序完成
        if not swapped:
            break
    return arr


# 示例
arr = [64, 34, 25, 12, 22, 11, 90]
print(bubble_sort(arr))
# 输出: [11, 12, 22, 25, 34, 64, 90]
```

## 复杂度分析

| 复杂度类型 | 复杂度 | 说明 |
|-----------|--------|------|
| 最好时间复杂度 | O(n) | 数组已经有序，只需一轮遍历 |
| 最坏时间复杂度 | O(n²) | 数组完全逆序 |
| 平均时间复杂度 | O(n²) | 随机排列的数组 |
| 空间复杂度 | O(1) | 只需要常数级别的额外空间 |

## 稳定性分析

冒泡排序是**稳定排序**。

在比较相邻元素时，只有当前一个元素**严格大于**后一个元素时才进行交换。对于值相等的元素，它们不会被交换，因此相同值的元素在排序后仍然保持原来的相对顺序。

例如，对于数组 `[3a, 2, 3b, 1]`（3a 和 3b 值相同），排序后的结果为 `[1, 2, 3a, 3b]`，3a 仍在 3b 之前。

## 适用场景

冒泡排序适合在以下场景中使用：

- **教学演示**：作为排序算法的入门教学示例
- **数据量较小**：当待排序的数据规模很小（n < 50）时，性能差异不明显
- **数据基本有序**：当数组已经"几乎有序"时，优化后的冒泡排序接近 O(n)
- **对稳定性有要求**：需要保持相同元素的相对顺序
- **内存受限**：只需 O(1) 额外空间

## 与其他排序算法的比较

| 算法 | 平均时间复杂度 | 最坏时间复杂度 | 空间复杂度 | 稳定性 |
|------|--------------|--------------|-----------|--------|
| 冒泡排序 | O(n²) | O(n²) | O(1) | 稳定 |
| 选择排序 | O(n²) | O(n²) | O(1) | 不稳定 |
| 插入排序 | O(n²) | O(n²) | O(1) | 稳定 |
| 归并排序 | O(n log n) | O(n log n) | O(n) | 稳定 |
| 快速排序 | O(n log n) | O(n²) | O(log n) | 不稳定 |

**与选择排序比较**：两者时间复杂度相同，但冒泡排序是稳定的，且在数据基本有序时可以提前终止。选择排序的交换次数更少（每轮最多一次交换）。

**与插入排序比较**：两者在最好情况下都是 O(n)，但插入排序通常比冒泡排序更快，因为插入排序的内层循环可以提前终止，且赋值操作比交换操作更高效。

**总结**：冒泡排序虽然简单易懂，但在大多数实际应用中，插入排序是更好的 O(n²) 级别算法选择，而对于大规模数据则应使用归并排序或快速排序。
