## 概述

归并排序（Merge Sort）是一种基于**分治法**（Divide and Conquer）的高效排序算法，由约翰·冯·诺伊曼在 1945 年发明。它将数组递归地分成两半，对每一半分别排序，然后将两个有序的子数组合并成一个有序数组。

归并排序的时间复杂度在所有情况下都是 O(n log n)，这使得它在处理大规模数据时比 O(n²) 的简单排序算法快得多。同时它是稳定排序，在需要保持相同元素相对顺序的场景中非常有用。

## 算法原理

归并排序采用经典的分治策略：

### 分（Divide）
将待排序的数组从中间分成两个子数组，递归地对这两个子数组进行归并排序。

### 治（Conquer）
当子数组的长度为 1 时（只有一个元素），认为它已经有序，开始回溯合并。

### 合（Merge）
将两个已排序的子数组合并成一个有序数组。合并过程使用双指针技术：
1. 创建一个临时数组用于存放合并结果
2. 设置两个指针分别指向两个子数组的起始位置
3. 比较两个指针所指元素，将较小的放入临时数组，并移动对应指针
4. 当某个子数组遍历完后，将另一个子数组的剩余元素直接复制到临时数组
5. 将临时数组的内容复制回原数组

## 执行步骤

以数组 `[64, 34, 25, 12, 22, 11, 90]` 为例，展示归并排序的执行过程：

**分解阶段（递归拆分）：**

```
                [64, 34, 25, 12, 22, 11, 90]
               /                             \
      [64, 34, 25, 12]                [22, 11, 90]
      /            \                  /          \
  [64, 34]      [25, 12]         [22, 11]      [90]
  /     \       /     \          /     \
[64]   [34]  [25]   [12]     [22]   [11]
```

**合并阶段（从底向上合并）：**

第一层合并：
- [64] 和 [34] 合并 → [34, 64]
- [25] 和 [12] 合并 → [12, 25]
- [22] 和 [11] 合并 → [11, 22]
- [90] 保持不变 → [90]

第二层合并：
- [34, 64] 和 [12, 25] 合并 → [12, 25, 34, 64]
  - 比较 34 和 12 → 取 12
  - 比较 34 和 25 → 取 25
  - 比较 34 和（右侧空）→ 取 34, 64
- [11, 22] 和 [90] 合并 → [11, 22, 90]
  - 比较 11 和 90 → 取 11
  - 比较 22 和 90 → 取 22
  - 左侧空 → 取 90

第三层合并：
- [12, 25, 34, 64] 和 [11, 22, 90] 合并 → [11, 12, 22, 25, 34, 64, 90]
  - 比较 12 和 11 → 取 11
  - 比较 12 和 22 → 取 12
  - 比较 25 和 22 → 取 22
  - 比较 25 和 90 → 取 25
  - 比较 34 和 90 → 取 34
  - 比较 64 和 90 → 取 64
  - 左侧空 → 取 90

**最终结果：[11, 12, 22, 25, 34, 64, 90]**

## 代码实现

```java
public class MergeSort {

    /**
     * 归并排序主方法
     */
    public static void mergeSort(int[] arr, int left, int right) {
        if (left < right) {
            int mid = left + (right - left) / 2;
            // 递归排序左半部分
            mergeSort(arr, left, mid);
            // 递归排序右半部分
            mergeSort(arr, mid + 1, right);
            // 合并两个有序子数组
            merge(arr, left, mid, right);
        }
    }

    /**
     * 合并两个有序子数组
     */
    private static void merge(int[] arr, int left, int mid, int right) {
        int n1 = mid - left + 1;
        int n2 = right - mid;

        // 创建临时数组
        int[] leftArr = new int[n1];
        int[] rightArr = new int[n2];

        // 复制数据到临时数组
        System.arraycopy(arr, left, leftArr, 0, n1);
        System.arraycopy(arr, mid + 1, rightArr, 0, n2);

        // 合并临时数组
        int i = 0, j = 0, k = left;
        while (i < n1 && j < n2) {
            if (leftArr[i] <= rightArr[j]) {
                arr[k] = leftArr[i];
                i++;
            } else {
                arr[k] = rightArr[j];
                j++;
            }
            k++;
        }

        // 复制剩余元素
        while (i < n1) {
            arr[k] = leftArr[i];
            i++;
            k++;
        }
        while (j < n2) {
            arr[k] = rightArr[j];
            j++;
            k++;
        }
    }

    public static void main(String[] args) {
        int[] arr = {64, 34, 25, 12, 22, 11, 90};
        mergeSort(arr, 0, arr.length - 1);
        System.out.println(java.util.Arrays.toString(arr));
        // 输出: [11, 12, 22, 25, 34, 64, 90]
    }
}
```

```python
def merge_sort(arr):
    """归并排序"""
    if len(arr) <= 1:
        return arr

    # 分：将数组分为两半
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])

    # 合：合并两个有序数组
    return merge(left, right)


def merge(left, right):
    """合并两个有序数组"""
    result = []
    i = j = 0

    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1

    # 添加剩余元素
    result.extend(left[i:])
    result.extend(right[j:])
    return result


# 示例
arr = [64, 34, 25, 12, 22, 11, 90]
print(merge_sort(arr))
# 输出: [11, 12, 22, 25, 34, 64, 90]
```

## 复杂度分析

| 复杂度类型 | 复杂度 | 说明 |
|-----------|--------|------|
| 最好时间复杂度 | O(n log n) | 无论数据如何，都需要完整的分解和合并过程 |
| 最坏时间复杂度 | O(n log n) | 同上 |
| 平均时间复杂度 | O(n log n) | 同上 |
| 空间复杂度 | O(n) | 需要额外的临时数组存储合并结果 |

**为什么是 O(n log n)**：
- 递归深度为 log n（每次将数组分为两半）
- 每一层的合并操作总共需要 O(n) 时间
- 因此总时间 = O(n) × O(log n) = O(n log n)

## 稳定性分析

归并排序是**稳定排序**。

在合并过程中，当左右子数组中的元素相等时（`leftArr[i] <= rightArr[j]`），我们优先取左侧的元素。由于左侧子数组中的元素在原数组中位于右侧子数组中相同值元素之前，这样就保证了相同值元素的相对顺序不变。

关键在于合并时使用 `<=` 而非 `<` 来比较，确保相等元素时优先选择左侧元素。

## 适用场景

归并排序适合在以下场景中使用：

- **大规模数据排序**：O(n log n) 的时间复杂度使其适合处理大量数据
- **对稳定性有要求**：需要保持相同元素的相对顺序（如数据库排序）
- **链表排序**：归并排序在链表上的实现不需要额外空间（可以直接修改指针）
- **外部排序**：当数据量太大无法全部加载到内存时，归并排序的思想非常适合外部排序
- **需要保证最坏情况性能**：不像快速排序在最坏情况下退化为 O(n²)

## 与其他排序算法的比较

| 算法 | 平均时间复杂度 | 最坏时间复杂度 | 空间复杂度 | 稳定性 |
|------|--------------|--------------|-----------|--------|
| 归并排序 | O(n log n) | O(n log n) | O(n) | 稳定 |
| 快速排序 | O(n log n) | O(n²) | O(log n) | 不稳定 |
| 堆排序 | O(n log n) | O(n log n) | O(1) | 不稳定 |
| 插入排序 | O(n²) | O(n²) | O(1) | 稳定 |
| 冒泡排序 | O(n²) | O(n²) | O(1) | 稳定 |

**与快速排序比较**：归并排序的最坏情况仍然是 O(n log n)，而快速排序最坏情况为 O(n²)。但快速排序的平均常数系数更小，且空间复杂度更低 O(log n)，所以实际中快速排序通常更快。

**与堆排序比较**：两者最坏情况都是 O(n log n)，但堆排序空间复杂度为 O(1)，而归并排序需要 O(n) 额外空间。归并排序的优势在于稳定性和更好的缓存性能。

**总结**：归并排序是最可靠的 O(n log n) 排序算法之一，在需要稳定排序、外部排序或链表排序的场景中是首选。其主要缺点是需要 O(n) 的额外空间。
