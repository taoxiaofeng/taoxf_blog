## 概述

基数排序（Radix Sort）是一种**非比较排序**算法，它不通过比较元素大小来确定顺序，而是按照元素的每一位（从最低位到最高位，或从最高位到最低位）依次进行排序。每一位的排序使用稳定排序算法（通常是计数排序）作为子过程。

基数排序最初用于卡片排序机对穿孔卡片的排序。它特别适合处理整数或固定长度字符串的排序，时间复杂度为 O(d*(n+k))，其中 d 是最大位数，n 是元素个数，k 是每一位的取值范围（如十进制为 10）。

## 算法原理

基数排序有两种实现方式：

### LSD（Least Significant Digit）- 从最低位开始
1. 从最低有效位（个位）开始
2. 按照当前位对所有元素进行稳定排序
3. 移到下一位（十位、百位...），重复步骤 2
4. 直到处理完最高位，排序完成

### MSD（Most Significant Digit）- 从最高位开始
1. 从最高有效位开始
2. 按当前位排序后，将元素分成多个桶
3. 对每个桶递归地按下一位排序
4. 合并所有桶

**为什么 LSD 有效？**
关键在于每一位的排序必须是**稳定排序**。当我们按高位排序时，如果两个元素的高位相同，由于底层排序的稳定性，它们的相对顺序由之前的低位排序决定——而低位已经排好了。

本文主要介绍更常用的 LSD 基数排序。

## 执行步骤

以数组 `[64, 34, 25, 12, 22, 11, 90]` 为例，展示 LSD 基数排序的执行过程：

**确定最大值**：90，共 2 位数

**第一轮：按个位排序**

各元素的个位：
- 64 → 4
- 34 → 4
- 25 → 5
- 12 → 2
- 22 → 2
- 11 → 1
- 90 → 0

按个位稳定排序后：
| 个位值 | 元素 |
|--------|------|
| 0 | 90 |
| 1 | 11 |
| 2 | 12, 22 |
| 4 | 64, 34 |
| 5 | 25 |

排序结果：[90, 11, 12, 22, 64, 34, 25]

**第二轮：按十位排序**

各元素的十位：
- 90 → 9
- 11 → 1
- 12 → 1
- 22 → 2
- 64 → 6
- 34 → 3
- 25 → 2

按十位稳定排序后：
| 十位值 | 元素 |
|--------|------|
| 1 | 11, 12 |
| 2 | 22, 25 |
| 3 | 34 |
| 6 | 64 |
| 9 | 90 |

排序结果：[11, 12, 22, 25, 34, 64, 90]

注意：11 和 12 的十位相同（都是 1），它们的相对顺序由上一轮（个位）的排序结果决定。由于使用稳定排序，个位排序中 11 在 12 前面，所以这里仍然保持该顺序。

**最终结果：[11, 12, 22, 25, 34, 64, 90]**

## 代码实现

```java
public class RadixSort {

    /**
     * 基数排序（LSD，从最低位到最高位）
     */
    public static void radixSort(int[] arr) {
        if (arr.length == 0) return;

        // 找到最大值，确定最大位数
        int max = arr[0];
        for (int num : arr) {
            max = Math.max(max, num);
        }

        // 从个位开始，对每一位进行计数排序
        for (int exp = 1; max / exp > 0; exp *= 10) {
            countingSortByDigit(arr, exp);
        }
    }

    /**
     * 按指定位进行计数排序
     * @param exp 位数（1=个位，10=十位，100=百位...）
     */
    private static void countingSortByDigit(int[] arr, int exp) {
        int n = arr.length;
        int[] output = new int[n];
        int[] count = new int[10]; // 每一位的取值范围是 0-9

        // 统计当前位每个数字出现的次数
        for (int num : arr) {
            int digit = (num / exp) % 10;
            count[digit]++;
        }

        // 计算前缀和
        for (int i = 1; i < 10; i++) {
            count[i] += count[i - 1];
        }

        // 从后往前遍历，保证稳定性
        for (int i = n - 1; i >= 0; i--) {
            int digit = (arr[i] / exp) % 10;
            output[count[digit] - 1] = arr[i];
            count[digit]--;
        }

        // 复制回原数组
        System.arraycopy(output, 0, arr, 0, n);
    }

    public static void main(String[] args) {
        int[] arr = {64, 34, 25, 12, 22, 11, 90};
        radixSort(arr);
        System.out.println(java.util.Arrays.toString(arr));
        // 输出: [11, 12, 22, 25, 34, 64, 90]
    }
}
```

```python
def radix_sort(arr):
    """基数排序（LSD，从最低位到最高位）"""
    if not arr:
        return arr

    # 找到最大值，确定最大位数
    max_val = max(arr)

    # 从个位开始，对每一位进行计数排序
    exp = 1
    while max_val // exp > 0:
        counting_sort_by_digit(arr, exp)
        exp *= 10

    return arr


def counting_sort_by_digit(arr, exp):
    """按指定位进行计数排序"""
    n = len(arr)
    output = [0] * n
    count = [0] * 10  # 每一位的取值范围是 0-9

    # 统计当前位每个数字出现的次数
    for num in arr:
        digit = (num // exp) % 10
        count[digit] += 1

    # 计算前缀和
    for i in range(1, 10):
        count[i] += count[i - 1]

    # 从后往前遍历，保证稳定性
    for i in range(n - 1, -1, -1):
        digit = (arr[i] // exp) % 10
        output[count[digit] - 1] = arr[i]
        count[digit] -= 1

    # 复制回原数组
    for i in range(n):
        arr[i] = output[i]


# 示例
arr = [64, 34, 25, 12, 22, 11, 90]
print(radix_sort(arr))
# 输出: [11, 12, 22, 25, 34, 64, 90]
```

## 复杂度分析

| 复杂度类型 | 复杂度 | 说明 |
|-----------|--------|------|
| 最好时间复杂度 | O(d*(n+k)) | d 为最大位数，k 为基数（通常为 10） |
| 最坏时间复杂度 | O(d*(n+k)) | 所有情况下相同 |
| 平均时间复杂度 | O(d*(n+k)) | 所有情况下相同 |
| 空间复杂度 | O(n + k) | 需要输出数组 O(n) 和计数数组 O(k) |

**各变量含义**：
- n：待排序元素个数
- d：最大元素的位数（如 999 有 3 位，d=3）
- k：每一位的取值范围（十进制为 10，二进制为 2）

**与比较排序的关系**：
- 当 d 为常数且 k = O(n) 时，基数排序时间复杂度为 O(n)
- 当 d = O(log n) 时，基数排序时间复杂度为 O(n log n)，与比较排序相同

## 稳定性分析

基数排序是**稳定排序**。

基数排序的稳定性依赖于其子过程的稳定性。由于我们使用计数排序（稳定）作为每一位的排序子程序，且计数排序从后往前遍历原数组保证了稳定性，所以整个基数排序过程是稳定的。

稳定性在基数排序中至关重要：
- 当按高位排序时，相同高位的元素需要保持低位排序的结果
- 如果子过程不稳定，低位排序的结果会被破坏，导致最终结果错误

## 适用场景

基数排序适合在以下场景中使用：

- **整数排序**：特别是位数不多的非负整数
- **固定长度字符串排序**：如电话号码、身份证号、邮政编码
- **数据范围大但位数少**：如排序 100 万个三位数，d=3, n=1000000
- **需要线性时间排序**：当 d 和 k 为常数时，可达 O(n)
- **需要稳定排序**：基数排序是稳定的

**不适合的场景**：
- 浮点数排序（需要特殊处理）
- 位数差异很大的数据（最大位数决定了总体开销）
- 数据量小时，开销不如快速排序等简单

## 与其他排序算法的比较

| 算法 | 平均时间复杂度 | 空间复杂度 | 稳定性 | 排序方式 |
|------|--------------|-----------|--------|---------|
| 基数排序 | O(d*(n+k)) | O(n + k) | 稳定 | 非比较 |
| 计数排序 | O(n + k) | O(n + k) | 稳定 | 非比较 |
| 桶排序 | O(n + k) | O(n + k) | 稳定 | 非比较 |
| 快速排序 | O(n log n) | O(log n) | 不稳定 | 比较 |
| 归并排序 | O(n log n) | O(n) | 稳定 | 比较 |

**与计数排序比较**：
- 计数排序要求数据范围 k 不太大，基数排序通过"按位处理"突破了这个限制
- 例如排序 0-999999 的数，计数排序需要 k=1000000 的数组，而基数排序只需 k=10 的数组处理 6 轮

**与快速排序比较**：
- 当 d 为常数时，基数排序 O(n) 优于快速排序 O(n log n)
- 但基数排序需要 O(n) 额外空间，快速排序只需 O(log n)
- 快速排序的缓存性能通常更好

**何时选择基数排序**：
1. 排序大量整数且位数有限（如 32 位整数）
2. 需要稳定的线性时间排序
3. 数据范围大但位数少
4. 排序固定长度的键（如字符串、日期）

**总结**：基数排序通过"化整为零"的思想，将大范围的排序问题分解为多轮小范围的排序问题（每位 0-9），在整数排序和固定长度字符串排序场景中效率极高。
