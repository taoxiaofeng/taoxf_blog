## 概述

插入排序（Insertion Sort）是一种简单直观的排序算法。它的工作方式类似于我们整理扑克牌的过程：每次从牌堆中拿起一张牌，将其插入到手中已排好序的牌的正确位置。

插入排序是所有 O(n²) 级别排序算法中实际表现最好的一个。它在数据基本有序时效率极高（接近 O(n)），且是稳定排序，因此在实际应用中比冒泡排序和选择排序更为常用。许多高级排序算法（如 TimSort）在小规模子数组上都会使用插入排序。

## 算法原理

插入排序的工作方式如下：

1. 将数组分为已排序部分和未排序部分，初始时已排序部分只包含第一个元素
2. 取出未排序部分的第一个元素作为"待插入元素"
3. 在已排序部分中从后往前扫描，找到待插入元素应该插入的位置
4. 将已排序部分中比待插入元素大的元素依次向后移动一位
5. 将待插入元素放到正确位置
6. 重复步骤 2-5，直到未排序部分为空

### 核心思想

- 维护一个已排序的子数组（左侧）
- 每次将一个新元素插入到已排序子数组的正确位置
- 通过"移位"而非"交换"来为新元素腾出空间

## 执行步骤

以数组 `[64, 34, 25, 12, 22, 11, 90]` 为例，展示插入排序的执行过程：

**初始状态：** 已排序部分=[64]，未排序部分=[34, 25, 12, 22, 11, 90]

**第一轮（i=1），待插入元素=34：**
- 与 64 比较，34 < 64，将 64 后移
- 已无更多元素比较，将 34 插入位置 0
- 结果：[**34, 64**, 25, 12, 22, 11, 90]

**第二轮（i=2），待插入元素=25：**
- 与 64 比较，25 < 64，将 64 后移
- 与 34 比较，25 < 34，将 34 后移
- 已无更多元素比较，将 25 插入位置 0
- 结果：[**25, 34, 64**, 12, 22, 11, 90]

**第三轮（i=3），待插入元素=12：**
- 与 64 比较，12 < 64，将 64 后移
- 与 34 比较，12 < 34，将 34 后移
- 与 25 比较，12 < 25，将 25 后移
- 已无更多元素比较，将 12 插入位置 0
- 结果：[**12, 25, 34, 64**, 22, 11, 90]

**第四轮（i=4），待插入元素=22：**
- 与 64 比较，22 < 64，将 64 后移
- 与 34 比较，22 < 34，将 34 后移
- 与 25 比较，22 < 25，将 25 后移
- 与 12 比较，22 > 12，停止
- 将 22 插入位置 1
- 结果：[**12, 22, 25, 34, 64**, 11, 90]

**第五轮（i=5），待插入元素=11：**
- 依次与 64、34、25、22、12 比较，全部后移
- 将 11 插入位置 0
- 结果：[**11, 12, 22, 25, 34, 64**, 90]

**第六轮（i=6），待插入元素=90：**
- 与 64 比较，90 > 64，无需移动
- 90 保持在当前位置
- 结果：[**11, 12, 22, 25, 34, 64, 90**]

**最终结果：[11, 12, 22, 25, 34, 64, 90]**

## 代码实现

```java
public class InsertionSort {

    /**
     * 插入排序
     */
    public static void insertionSort(int[] arr) {
        int n = arr.length;
        for (int i = 1; i < n; i++) {
            int key = arr[i]; // 待插入元素
            int j = i - 1;
            // 将比 key 大的元素向后移动
            while (j >= 0 && arr[j] > key) {
                arr[j + 1] = arr[j];
                j--;
            }
            // 将 key 插入正确位置
            arr[j + 1] = key;
        }
    }

    public static void main(String[] args) {
        int[] arr = {64, 34, 25, 12, 22, 11, 90};
        insertionSort(arr);
        System.out.println(java.util.Arrays.toString(arr));
        // 输出: [11, 12, 22, 25, 34, 64, 90]
    }
}
```

```python
def insertion_sort(arr):
    """插入排序"""
    n = len(arr)
    for i in range(1, n):
        key = arr[i]  # 待插入元素
        j = i - 1
        # 将比 key 大的元素向后移动
        while j >= 0 and arr[j] > key:
            arr[j + 1] = arr[j]
            j -= 1
        # 将 key 插入正确位置
        arr[j + 1] = key
    return arr


# 示例
arr = [64, 34, 25, 12, 22, 11, 90]
print(insertion_sort(arr))
# 输出: [11, 12, 22, 25, 34, 64, 90]
```

## 复杂度分析

| 复杂度类型 | 复杂度 | 说明 |
|-----------|--------|------|
| 最好时间复杂度 | O(n) | 数组已经有序，内层循环不执行 |
| 最坏时间复杂度 | O(n²) | 数组完全逆序，每个元素都要移到最前面 |
| 平均时间复杂度 | O(n²) | 随机排列的数组 |
| 空间复杂度 | O(1) | 只需要常数级别的额外空间（一个临时变量） |

**移动次数分析**：
- 最好情况：0 次移动（已排序）
- 最坏情况：n(n-1)/2 次移动（逆序）
- 平均情况：n(n-1)/4 次移动

## 稳定性分析

插入排序是**稳定排序**。

在比较过程中，只有当已排序部分的元素**严格大于**待插入元素时，才会将其后移。对于值相等的元素，待插入元素会被放在相同值元素的后面，从而保持了相同值元素的相对顺序。

例如，对于数组 `[3a, 2, 3b, 1]`：
- 排序过程中 3b 插入时遇到 3a，由于 3a 不大于 3b，3b 会被放在 3a 后面
- 最终结果：`[1, 2, 3a, 3b]`，相对顺序保持不变

## 适用场景

插入排序适合在以下场景中使用：

- **数据基本有序**：当数组大部分已排序（只有少量元素无序）时，插入排序接近 O(n)，非常高效
- **数据量较小**：当 n 较小（通常 n ≤ 50）时，插入排序的常数系数小，表现优异
- **在线排序**：数据是逐个到达的，每来一个新数据就插入到已排序序列中
- **作为高级算法的子程序**：TimSort、IntroSort 等高级排序算法在小规模子数组上使用插入排序
- **对稳定性有要求**：需要保持相同元素的相对顺序

## 与其他排序算法的比较

| 算法 | 平均时间复杂度 | 最坏时间复杂度 | 空间复杂度 | 稳定性 | 最好情况 |
|------|--------------|--------------|-----------|--------|---------|
| 插入排序 | O(n²) | O(n²) | O(1) | 稳定 | O(n) |
| 冒泡排序 | O(n²) | O(n²) | O(1) | 稳定 | O(n) |
| 选择排序 | O(n²) | O(n²) | O(1) | 不稳定 | O(n²) |
| 归并排序 | O(n log n) | O(n log n) | O(n) | 稳定 | O(n log n) |
| 快速排序 | O(n log n) | O(n²) | O(log n) | 不稳定 | O(n log n) |

**与冒泡排序比较**：插入排序通常比冒泡排序快 2 倍左右。因为插入排序使用"移位"操作（一次赋值），而冒泡排序使用"交换"操作（三次赋值）。

**与选择排序比较**：插入排序在最好情况下为 O(n)，而选择排序始终为 O(n²)。在数据基本有序的情况下，插入排序的优势非常明显。

**为什么实际中常用**：Java 的 `Arrays.sort()` 和 Python 的 `sorted()` 使用的 TimSort 算法，在处理小数组（通常 ≤ 32 或 ≤ 64 个元素）时就是使用插入排序，因为在小规模数据上它的常数系数极小且缓存友好。
